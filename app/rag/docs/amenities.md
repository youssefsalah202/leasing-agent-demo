# Amenities

The community includes a resort-style pool with a sundeck, a 24-hour fitness center, a resident clubhouse with free Wi-Fi and coworking space, and a dog park.

Each unit comes with a full-size washer and dryer, stainless steel appliances, and a private patio or balcony.

Select units include a walk-in closet and a home office nook — ask your leasing agent which floor plans include these features.

Package lockers are available 24/7 near the main entrance for secure deliveries.
